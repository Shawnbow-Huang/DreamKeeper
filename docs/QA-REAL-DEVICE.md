# 梦匣 0.10.1 · 真机回归清单（含模型发现 / 双模型 / 三套皮肤）

> 目标：在真机上确认「能装、能录、能转写、能整理、能小说化、能改稿、能导出」，并把环境差异（STT、麦克风、权限、通知）的问题抓出来。
> 版本：`0.11.0 / versionCode 5`（release，已签名；修复转写卡死与「等多久」可见）
> 环境基线：模拟器已过 **66 类 / 526 例** JVM 测试（含模型发现、双模型、模型下拉）；本清单只覆盖真机差异项。
> 预计用时：35–50 分钟。每一项都有「期望」，不符合就记下来，不用当场修。

## 0. 准备

- [ ] 设备：Android 8.0（API 26）及以上，建议 Android 12+；剩余存储 ≥ 1 GB。
- [ ] 安装包：`DreamKeeper-0.11.0.apk`（见交付消息里的路径与 sha256）。
- [ ] 电脑装好 `adb`（可选；不用 adb 也可用文件传输安装）。
- [ ] 允许「安装未知来源应用」。
- [ ] 记录环境（回传时贴这段）：

```

APK sha256：

```

安装（任选一种）：

```bash
# 方式 A：adb
adb install -r DreamKeeper-0.10.0.apk

# 若提示签名冲突（装过旧 debug 包或 0.9.0 之外签名的包）：

```

> ⚠️ 卸载会清空本机梦境数据（含录音）。若设备上有旧版本数据，先确认是否要保留；同签名 0.9.0 → 0.10.0 可直接覆盖升级，数据保留。

## 3.5 内置语音识别（0.11.0 新增，重点）

- [ ] 装好后**断网 + 飞行模式**，录 30 秒说一段中文，停在「追问」页，观察原样 tab。
- [ ] 预期：10–20 秒内出现带标点的中文转写；**不再出现「下载中文语音包」**，也不再要求联网。
- [ ] 设置页滚到「语音识别」：应显示「内置 SenseVoice Small / 离线转写随包安装」。
- [ ] 再录一条 2 分钟以上的，检查接缝处（每 25 秒一处）有没有重复半句或吞字；
      有的话记下时间点，这是分段算法的已知风险。
- [ ] 如果转写失败：先看 `adb logcat -s DreamStt`，把 `sensevoice done` / `segment` 行贴回来。
- [ ] 如果界面停在「正在转写…」超过 90 秒：应显示「可能已经卡住」，点「重新转写」；
      若仍不动，在电脑上 `adb logcat -s TranscriptWriter DreamStt` 取证（0.11.3 起失败会落 FAILED，不再无限等）。
- [ ] 60 秒以上录音检查 25 秒接缝处是否还有「同一个词读两遍」（0.11.3 改为按正文比对拼接）。
- [ ] 注意安装包约 323MiB，安装与首次打开会明显比之前慢；首次转写要等模型加载（1–2 秒）。

## 10. 证据回收方式

真机 release 包 **不可 `run-as`**，所以数据库/文件拉不出来，按下面交：

1. **截图**：命名 `rd-<序号>-<描述>.png`（如 `rd-02-3-test-connection-ok.png`）。至少交：首启空态、DeepSeek 测试连接成功、错误 Key 失败、转写成功、小说化生成、导出文件列表。
2. **日志**（若用 adb）：

```bash
adb logcat -c
# ……操作……
adb logcat -d | grep -E "FATAL|DKLLM|DKConn|DKKey" > rd-logcat.txt
```

   - `FATAL` 应为 0 行；`DKConn` 会有一条测试连接记录；`DKLLM` 是每次模型尝试。
   - 不要把 Key 贴进日志/截图（`DKKey` 只打「已配置/未配置」）。
3. **文字记录**：每项「不符合」写清：步骤 → 期望 → 实际 → 是否可复现。
4. **APK 信息**（装完随手记）：

```bash
adb shell dumpsys package com.dreamkeeper | grep -E "versionName|versionCode"
```
