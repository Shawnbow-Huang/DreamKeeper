# 原样整理 v3.1 设计：按整篇语义重写

日期：2026-11-01
状态：已与用户对齐（brainstorming 六问），待写实施计划
关联：`prompts/faithful.v3.md`、`llm/gates/FaithfulGates.kt`、`scripts/check-faithful.py`

## 1. 问题

v3 把「原样整理」定义成「事实守恒 + 压缩到五六成」，并用 F2（0.50–0.85）与 G5（好像次数守恒）把它钉死。真实 92 秒录音（380 字口水稿）跑出来：

- 压缩到 257 字时，同音错字仍留在正文（`进枪`、`标里`、`工略`），因为 v3 §2.9 只允许「本篇前文已出现过正确写法」才改；
- 用户手改的理想版是 **313 字（11 字的增量，不是压缩）**，且做了 4 处语义改字、3 处主语补全、1 句解释补写；
- 按现有闸门，这份手改稿会被 F2（313/294=1.06 超出 0.85）与 G5（好像 5→3）判红——**闸门判红的东西，正是用户想要的**。

结论：v3 的目标与闸门都需要换血。用户要的「原样」是**事实不改、读得通**，不是**变短**。

## 2. 目标与非目标

**目标**

1. 输出是一份「可以直接读给朋友听」的原样稿：口水、元叙述、原地重复清零；同音错字按整篇语义改对；主语/指代补到不歧义。
2. 事实一条不丢、一条不加：事件、人物、地点、物件、数字、动作、因果方向全部守恒。
3. 长度不设目标；处理完多少字就多少字。
4. 闸门与目标一致：不再用「压缩率」「模糊词次数」惩罚正确输出。

**非目标**

- 不做小说化/文学化（那是小说化链的事）。
- 不做「按常见搭配批量改错字」的确定性替换表。
- 不新增 UI 展示（同音改动只在内部审计）。
- 不改数据模型（沿用 `dreams.faithfulText` 与 `llm_calls`）。

## 3. 提示词 v3.1（`prompts/faithful.v3.1.md`）

相对 v3 的改动：

### 3.1 同音改字（放开依据范围）

旧（v3 §2.9.5）：「只认本篇前文已经出现过的字，不靠常见搭配猜」。

新：

> 依据是**整篇语义**：前文、后文、事件逻辑都算。只改「原字在这句里读不通、且整篇只有这一种读法成立」的字；不设处数上限；**禁止**用「常见搭配」当依据（两个读法都通时保持原字）。
>
> 例：`进枪`→`禁枪`（后文「不允许你带」「拿下来保管」才是依据，前文没出现过「禁枪」）；`标里`→`腰里`（「别着一把枪」的动作 + 身体部位）；`工略`→`攻略`；`也别的一把枪`→`也别着一把枪`。

### 3.2 解释可补（限 1–2 句）

- 只允许把原文**隐含的因果/感受**说明白（如「特别激动，因为……是一种非常新奇的体验」）。
- **不许**新增事件、人物、物件、地点、时间；不许新增对事实的断言。
- 全篇最多 2 句；超出即违规。

### 3.3 主语与指代补全

- 可补原文省略但语义唯一的主语/地点：`纠结`→`大家一起纠结`、`攻略没做好`→`大家对攻略也没做好`、`店门口说`→`店门口的人说`、`那里吃`→`到了澳门之后在那里吃`。
- 若补全需要「二选一」而原文没有依据，则保持原样，不猜。

### 3.4 不压缩

- 删除目标：不再要求「压缩到五六成」。
- 只做四件事：清口水、清元叙述、去原地重复、合并同义反复。
- 允许输出比原文长（补主语、补一句解释），也允许略短（重复被合并）；**信息量不得减少**。

### 3.5 数字

- 只修「明显不可能/自相矛盾」的数字：`4.4点钟`→`4点钟`、`3.7次`→按上下文取整；合理的小数与口语数字不动（`6点钟`、`4.4公里`）。
- 不把口语数字一律转成阿拉伯数字。

### 3.6 不确定词

- 叠字合并（`好像好像`→`好像`）、冗余可删；但**每个不确定的事实至少保留一个模糊词**（好像/大概/可能/记不清）。
- **禁止**把推测写成断言（`好像去了` ≠ `去了`）。

### 3.7 保留口吻

- 第一人称、口语节奏、结尾的「非常简短的一个梦」这类自述照留，不端着、不改成书面报告。

## 4. 闸门

| 闸门 | v3 | v3.1 |
| --- | --- | --- |
| F1 事实锚点 | 数字/地点/人物/物件/动作全部出现 | **保留**，锚点五类不变，判定按「规范化后子串」 |
| F2 压缩率 | 0.50–0.85 必须命中 | **降为异常报警**：`ratio < 0.60` 且 F1 有缺 → 红；`ratio > 1.40` → 红；其余不评分 |
| F3 口水 | 零口水 | **保留** |
| G4 元叙述 | 零 | 保留 |
| G5 模糊词 | 次数守恒（原文 N 次，输出 <N 即红） | **定性检查**：原文每个不确定事实在输出里仍带模糊词；不再数次数 |
| G6 改字审计 | faithful 不挂 | 不挂（同音改动只进审计日志） |

闸门细节：

- F1 锚点提取沿用 `anchors()`，但数字锚点先做「不可能数字」归一（`4.4点钟`→`4点钟`）再比对，避免用户手改版因合理修正被判红。
- F2 的 `ratio` 用「内容字数」计算（`[\u4e00-\u9fffA-Za-z0-9]`），与现有实现一致。
- G5 实现：对原文每个「模糊词 + 其后 N 字内的谓语」抽取 `(hedgedFact, hedgeWord)`；输出中该 fact 的规范化子串必须与某个模糊词共现（±12 字窗口）。

## 5. 审计

每次同音改动写一行内部审计（不进 UI）：

```
{"from":"进枪","to":"禁枪","reason":"后文 不允许你带 / 拿下来保管","prompt":"faithful.v3.1"}
```

落在 `llm_calls` 之外的调试日志（`DreamGen`，仅 debug 构建），不写数据库、不上传。

## 6. 测试

### 6.1 黄金用例（必须绿）

`docs/evidence/plan8/baseline-faithful-2026-11-01.txt` → `docs/evidence/plan8/user-edited-faithful-2026-11-01.txt`

- F1 全绿、F2 不红（ratio 313/294=1.06）、F3 零口水、G4 零元叙述、G5 定性通过。
- 逐条覆盖：禁枪 / 腰里 / 攻略 / 别着 / 4点钟 / 到了澳门之后 / 大家 / 店门口的人 / 解释句 / 好像合并。

### 6.2 合成向量（8 条，`docs/evidence/plan8/faithful-v31-vectors.json`）

1. 语义改字：前文无依据、后文可推（`进枪`→`禁枪`）→ 通过。
2. 两读皆通（`开饭/开放`）→ 必须保持原字，不得改。
3. 常见搭配陷阱（`在座上` 不动）→ 不得按搭配改。
4. 补解释超 2 句 → 红（规则 2 违规）。
5. 新增人物/地点（原文没有「母亲」，输出加了）→ F1 红。
6. 丢事实（漏掉「6点钟到」）→ F1 红。
7. 口水残留（`呃`）→ F3 红。
8. 断言化（`好像去了`→`去了`）→ G5 红。

### 6.3 回归

- 既有 530+ 单测全绿；`check-faithful.py --self-test` 与 `--vectors` 扩到新向量。
- 真机：92 秒录音重跑一次，人工对照七条规则逐条勾。

## 8. 验收

1. 真机同一段录音，输出满足七条规则；不再出现「按闸门红、按人眼好」的冲突。
2. 黄金用例在单测中稳定通过（固定输入输出，不调模型）。
3. 至少 3 段不同的真实录音人工抽检：无错字残留、无新增事实、无断言化。
4. `docs/evidence/plan8/ACCEPTANCE-v31.md` 记录每段录音的规则勾选与残留问题。

## 9. 风险

- **过度改字**：整篇语义判断放宽后，模型可能把「做」改成「坐」之外的更多字。缓解：只允许「读不通」的字；两读皆通不动；黄金用例 + 合成向量 2/3 专门盯这个。
- **解释句变注水**：1–2 句的限制靠提示词自律，闸门只能查「新增实体」（F1）。缓解：抽检 + 若出现注水，加 N 字上限（输出比原文多 80 字以上）为二级报警。
- **G5 定性判定不稳**：模糊词窗口匹配可能漏判。缓解：先按 12 字窗口实现，抽检后调窗口。
