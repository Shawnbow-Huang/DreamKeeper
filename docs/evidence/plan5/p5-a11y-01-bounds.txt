# p5-a11y-01-bounds.txt — T6 触控目标 ≥48dp（1.3× 字号下实测）

## 怎么测
1. `adb shell settings put system font_scale 1.3`，`force-stop` 后冷启；
2. 进 10月8日「教室」→「小说化」tab（版本线 + 快捷 chips 同屏）；
3. `adb shell uiautomator dump /sdcard/ui3.xml` 后 `exec-out cat` 拉回，解析所有 `clickable="true"` 节点；
4. 设备 1080×2400 / 420dpi → 48dp = 126px，判据 `height >= 126`。

## 结果
clickable 节点 **17 个，全部 ≥126px，0 个低于门槛**。抽样（原始 bounds）：

```
版本线 chip v9   [42,704][297,830]    h=126
版本线 chip v8   [318,704][573,830]   h=126
版本线 chip v7   [594,704][1080,830]  h=126
快捷 chips（4 枚同排）
                 [42,1830][266,1956]  h=126
                 [287,1830][511,1956] h=126
                 [532,1830][796,1956] h=126
                 [817,1830][1038,1956] h=126
tab（原样/小说化/标签/素材）
                 [42,189][291,315]    h=126
返回/更多        [11,63][137,189]     h=126  [943,63][1069,189] h=126
```
完整 17 行原始 bounds 见 `.scratch/ui3.xml`（不入库，可用上面 REPLAY 重现）。

## 读法
- 「可视胶囊」仍是 36dp（`VersionChip` 内层 `height(36.dp)`），但外层 `Box(heightIn(min = 48.dp))` 承担点击；因此截图里胶囊看起来没变高，点击区却从 36dp 扩到 48dp。
- 快捷 chips 同理（`ReviseSheet` 外层 Box 48dp + 内层胶囊 36dp）。
- 设置页的选择 chips 本来就是 `heightIn(min = 48.dp)`，未改。
