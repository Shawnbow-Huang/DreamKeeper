# 根因

`DreamKeeperApp.onCreate` 在 `appScope.launch` 里无条件（debug 下）跑 `SeedData.seedIfEmpty(container.database)`；
Robolectric 每个用例都会执行 `onCreate`，而 `DbBackupTest` / `MigrationTest` 会删除并重建
`databases/dreamkeeper.db`（含 `-wal/-shm`）。后到的 seed 协程可能打开一个「SQLite 认为是新建库、
但 schema 已非空」的半成品库，Room 在 `RoomOpenHelper.onCreate` 抛
`IllegalStateException: Pre-packaged database has an invalid schema`；
coroutines-test 把它记成「下一个用例开始前已有未捕获异常」，于是随机砸在别的用例上。
