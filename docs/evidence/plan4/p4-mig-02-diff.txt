# 本轮修掉的脚本缺陷（D422）
diff_2_3 原先直接用 dump 里带 `i:`/`s:` 前缀的字符串比较 `transcriptStatus == "OK"` 与
`transcriptMs == 0`，导致回填期望永远算成 0（真实数据必 RED）。已加 `decanon()` 去前缀，
并在比较时用 canon 形式（`i:0`/`i:2400`）。修后：
- 本 fixture GREEN、负向 RED
- v1→v2 回归仍 GREEN（p3-mig-01-baseline.json vs p3-mig-02-after.json，输出逐字不变）
