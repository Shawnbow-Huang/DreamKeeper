## 5. 未验证项（不当成果宣布）

1. **API 33+ 的文件转写正路径**（pipe → 分段 → `Ok`）：本机 `installed/supported/pending/online` 四张语言表全空，`availability = Unavailable`。需要一台装有中文离线识别包的 API 33+ 设备。
2. **真人语音**：模拟器未加 `-allow-host-audio`，输入全零，`RMS = -inf`；所有「有声音」的判断都只能写到「链路通、信号来源 = seam」。
3. 通话/来电场景的 §14.2；锁屏 `LOCK_TILE` 全链路；通知本体的「结束」按钮点回。
4. `appops ... RECORD_AUDIO ignore` 软拒路径（需 `--uid` 才生效）→ 结论「待实测」。
5. 真机磁盘写满（`ENOSPC`）——只用 DEBUG 注入模拟过。

## 6. 与设计文档的偏差（已在设计 v1.5 落定）
