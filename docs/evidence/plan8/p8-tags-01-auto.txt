# 为什么做
用户 2026-11-01 23:52：「现在开始吧。这版的整理效果我觉得挺好的」——批准在原样整理成功后自动打标签。

# 改法
1. `prompts/tag.v1.md`（sha `c2d9b4eb`）：3–6 个标签，name 1–8 字，kind ∈ PERSON/PLACE/OBJECT/ACTION/EMOTION/OTHER，
   evidence 必须是原样稿里逐字出现的片段，同名去重，只输出 JSON。
2. `PromptSpecs.TAG` + `TagExtractor`（剥围栏、数量/长度/kind/evidence 子串校验）。
3. `GenerationStore.saveAutoTags`：先删该梦 `source=AUTO` 的关联，再同名复用或新建 `tags` 行、插 `dream_tags`。
4. `GenerationOrchestrator.bestEffortTags`：原样整理成功后打一次 TAG（thinking OFF、temperature 0.2、jsonMode），失败只记日志不影响正文。
5. 标签页：`TagsTab` 读 `observeTagsForDream`，空态改「原样整理完成后会自动打 3–6 个标签」；长按胶囊弹确认后可删（只删关联）。
