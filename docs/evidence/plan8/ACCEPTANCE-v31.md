## 5. 已知残留与风险

1. 解释句是否出现取决于模型，规则只给上限，不给下限。
2. F 系列闸门兜不住「模型自造错字」（如包里→标里）；这类只能靠提示词与人工抽检。
3. 同音改字放宽到整篇语义后，过度改字的风险由 F1 与黄金用例共同约束；抽检仍需继续。
4. 真机 logcat 轮转快，E2E 以 UI 文本 + `faithful audit` 行 + 成本行为佐证。
