## 错误与 usage（`ProviderErrorsTest` 6 例 + `ProviderUsageTest` 3 例）
- **MiniMax HTTP 200 + `base_resp.status_code != 0`** 必须翻成 `BAD_REQUEST` 且**不重试**（attempts=1）。
- 401/403 → `AUTH`（只发一次）；429 → `RATE_LIMIT`（用满重试预算）；5xx → `SERVER`；4xx → `BAD_REQUEST`。
- 空 content → `EMPTY_CONTENT` 不重试；jsonMode 下非 JSON → `INVALID_JSON` 不重试。
- usage 三种形状：DeepSeek `prompt_cache_hit/miss`、OpenAI `prompt_tokens_details.cached_tokens`（命中=缓存，未命中=其余）、
  缺字段时回 0；`reasoning_tokens` 既认顶层也认 `completion_tokens_details`。
