# 为什么改
用户 2026-11-01 02:36：「设置里多个供应商，直接铺陈在设置里似乎有些不科学和不美观……学习一下它点击进去的界面排布」。
参考 Cherry Studio / Chatbox：索引与配置分离。用户逐项确认 D1–D5（见
docs/superpowers/specs/2026-11-01-provider-settings-ia-design.md）。

# 改法
1. 设置首页只留一行「模型服务」摘要（当前供应商 · 模型 · 已/未配置 Key）+ 外观 + 关于。
2. 新增「模型服务」列表页：五家行、使用中标记、配置状态点、行间发丝线；底部一句
   「每家一个独立 Key，互不串用；当前只有一家参与生成。测试连接在单家页面」。
3. 新增单家详情页：Key 卡（保存 / 测试连接 / 清除 + 结果行）、模型与思考卡、
   非 DeepSeek 的「暂无价卡，按未计价（0 元）记账」、底部「设为当前供应商 / 使用中」，
   未配 Key 时提示「可以先设为当前，但生成会失败」。
4. VM 拆分：ProviderListViewModel（rows/刷新/皮肤）+ ProviderDetailViewModel
   （initialProvider 钉死当前家；makeActive 只写 dk_generation_provider）。
5. 路由：settings/providers 与 settings/provider/{wire}；列表 onBack 先 refresh。
