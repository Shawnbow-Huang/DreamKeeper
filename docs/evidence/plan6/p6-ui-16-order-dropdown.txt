# 为什么改
用户 2026-11-01 03:19（配好 DeepSeek Key 后）：「假如某一个供应商有 3 个或者 4 个在供应的模型，是不是就会出现好几个圆角矩形……
用下拉框的方式来选择检测到的模型，会更加美观呢？同时，忠实整理模型和小说化模型，这两个在当前页面所在的位置，
让忠实整理模型相关选项在上，小说化模型相关选项在下，是否会更加符合逻辑呢？」

# 改法
1. 两个模型的候选从「胶囊平铺」改为**下拉**：一行当前值 + ▾，点开是候选清单（当前项 ember + ✓）。
   模型数不设上限，3–4 个也不会把卡片撑成两列；思考仍是 4 档胶囊（固定、需要一眼看全）。
2. 顺序改为 **忠实整理模型 → 小说化模型 → 小说化思考**：忠实是第一步、也是更省的一步，先出现符合使用顺序。
3. 下拉菜单容器用 `paperSurface` + 发丝线 + 8dp 阴影，与纸面材质一致（默认 M3 容器是淡紫 surface，和皮肤打架）。

# 真机验证（真实 Key，已保存 sk-...2605）
