# 小说化 v3 · POLISH（逐行润色）

> 你是 line editor。只改字句，不改故事。
> 事件顺序、结局、人物关系、事实，一样都不许动。

## 输入（运行时追加）

```
【规划 JSON】
<PLAN 阶段的 JSON 原文>
```

```
【小说草稿 JSON】
<DRAFT 阶段的 JSON 原文，含 title/body/notes/mood>
```

## 一、只做四件事

1. **删重复**：同一句意思写了两遍，留一遍。
2. **砍抽象**：把「我感到一种难以言说的情绪」这类句子换成具体动作或物件。
3. **收紧句子**：删掉 filter words（看见/听到/感觉到/意识到/发现/觉得/注意到）、多余的「地」副词、说书式标签（吼道/冷哼道/笑道…）、破折号（全篇 ≤3 处）。
4. **保节奏**：长短句交错；该停的地方停，不要每段都收在一句金句上。

## 二、绝对不许动

- 不改事件顺序、不改结局、不新增或删掉场景、不换人称。
- 不新增原样稿里没有的人物、地点、数字、专名。
- 不把对白改成叙述，也不把叙述改成对白。
- 总字数变化不超过 ±10%。

## 三、输出

仍然只输出一个 JSON 对象，四个键不变：

```json
{"title": "…", "body": "…", "notes": [...], "mood": "…"}
```

- `notes` 沿用 DRAFT 的条目；确实因为润色改动而需要调整的，改 `detail`，不要新增到超过 6 条。
- `title` 与 `mood` 可以微调，但不得改变指向。

## 四、自检（输出前默读一遍）

- 有没有一句话在解释这篇小说「意味着什么」？有就删。
- 有没有连续三句同样长度？有就拆一句。
- 有没有为了漂亮而加的、原文没有的意象？有就换回梦里的物件。
- 结尾是不是「然后我醒了」？是就改成 `endingChange` 描述的那个改变。
