# prompts/ · 提示词与评测集

跨平台共享资产。Android 通过 Gradle `sourceSets` 引入，iOS 直接读同一批文件。

## 约定

1. **提示词不进 Kotlin 代码。** 改一句话不该重编译，也不该翻遍源码找字符串。
2. **改了就是新版本。** `novel.v1.md` → `novel.v2.md`，旧版本保留，可回滚、可对比。
3. **四段式**，缺一段不算写完：

   ```
   角色     你是谁，在替谁做什么
   事实契约  哪些能改、哪些一个字都不许动
   风格契约  语言层面的硬要求（含禁用词表）
   输出格式  JSON schema，字段固定
   ```

## 文件清单（v1 计划）

| 文件 | 用途 | temperature |
|---|---|---|
| `novel.v1.md` | 小说化润色 | 0.9 |

| `changelog.v1.md` | 生成改动清单（模型自述补了什么） | 0.2 |

## 评测

改任何提示词，都必须跑 `docs/eval/` 下的评测集：

- `docs/eval/dreams.md` —— 20 条真实梦境（原文）
- `docs/eval/results.md` —— 每次提示词改版的打分记录

三条打分项：**像不像人写的（1–5）/ 有没有丢核心情节 / 有没有编造事实**。

没有跑评测的提示词改动，等于没改。
